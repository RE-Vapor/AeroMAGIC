# 阶段 4：12-NW-6C-7 公平实验、诊断与调参记录

本记录只覆盖 `12-NW-6C-7`。主实验使用同一真实 mesh reference、starts 0–4、
101 次观测、`random_seed=8`、`torch_seed=9`、beam `10×10`、legacy mapping
`2×`、hybrid segment collision、800k proxy points 与 100k GT surface points。
MAGICIAN 额外使用 occupancy → Imagined Gaussians → RaDe-GS 先验；SCONE
不使用 RaDe-GS。

## 数据契约与物理尺度

规划读取的 `Tile_+301_+146.obj` 已经物化了 recenter、z-up → y-up 旋转和
0.1 预处理缩放，因此正式 transform 是 identity，不能再次套用
`12-NW-6C-5` 的 world-coordinate transform。

```text
planning OBJ sha256  5a9f5f2794ddba344a6f35232cc9129dcddc5ee374ebaa67d248c5160b28200b
source backup sha256 a75925842a4580800e5f0ca59fd55d521f6dae2a42c648ed2e66d380c4bc4bbb
vertices             168,755

source min            [45149.648438, 21899.650391,  96.262398]
source max            [45300.351562, 22050.351562, 167.149994]
source extents        [  150.703124,   150.701171,  70.887596]

planning min          [-7.5351562, 0.0000000, -7.5351562]
planning max          [ 7.5351562, 7.0887596,  7.5349609]
planning extents      [15.0703124, 7.0887596, 15.0701171]
settings envelope     [15.3000000, 7.2000000, 15.3000000]
```

物理尺度锁定为 `scene_units_per_meter=1.0`。两条独立证据是：

1. 备份 OBJ 的水平范围与 `+301/+146` 编码的 150-unit dataset tile 网格一致；
   数据源 revision 固定为 `d9510f553fcc02e1fc1dc01ea56647fe4bc50c51`。
2. 备份 mesh 的每轴 extent 乘已物化的 0.1 后，与当前 mesh 一致，并完整落入
   独立 `settings.json` 包络；现有 runtime `scene_scale_factor=10` 后仍一致。

公式为 `1 meter/source-unit × 0.1 preprocessed-unit/source-unit × 10
scene-unit/preprocessed-unit = 1 scene-unit/meter`。该结论不得外推到 Eiffel 或
其他 12-NW 场景。

## 真实 mesh / CUDA 门禁

`scripts/validate_12nw_scene_contract.py` 使用规划入口同一个 transform、PyTorch3D
CUDA `MeshRasterizer`、start 0 真实相机和 coverage reference。正式门禁结果：

```text
gate_passed                                  true
renderer/collision max abs bbox difference  5e-7 scene units
mesh vertices inside coverage bounds         100%
mask                                         82,462 px / 70.6397%
finite depth                                 82,462 px
depth min / mean / max                       21.726 / 48.128 / 123.564 m
RGB finite                                   true
```

额外对 starts 0–4 全部执行真实 CUDA rasterization，五个 mask 均非空且有限，
覆盖比例分别为 `70.64% / 73.06% / 69.17% / 69.65% / 93.51%`。
`occupied_pose.pt` 含 1,008 个位置（592 occupied、416 free），五个正式起点均为
free。为与共享公平协议一致，两个规划器都设置
`validation_use_occupied_pose=false`，不使用 GT mesh pose-validity prior；GT mesh
segment collision 仍对二者开启。

## DA3 在线无泄漏 smoke

真实 RGB-only 三视图 smoke 使用三个非共线相邻 free pose；DA3 输入只含
RGB、相机内外参和历史状态，pose conditioning 生效且没有 fallback。共 116,736
个有限 depth pixel，预测范围 `19.027–108.419 m`，confidence 范围
`1.000–26.987`。renderer GT 只在进程退出后的隔离诊断读取：59,302 个 paired
pixel，depth MAE `2.315 m`、median AE `1.277 m`、P90 AE `4.854 m`、RMSE
`3.935 m`；这些量未反馈给在线 depth、confidence、cache key、点云、proxy、
候选评分或轨迹。cache miss/hit 分别为 `19.367 s / 0.020 s`，peak allocated /
reserved 为 `9,786.4 / 10,860 MiB`。

## 主结果

四组共 20/20 条轨迹均 exit 0；每组都覆盖 starts 0–4，每条轨迹都是 101
次观测。机器检查同时确认在线规划阶段没有读取 renderer GT，退出后的诊断量没有
反馈给规划器。下表均为五起点总体均值与总体标准差。

| 规划器 / depth source | normalized coverage | raw coverage | path (m) | trajectory / provider (s) | peak allocated (MiB) | pose-conditioned |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| MAGICIAN / GT | 0.709900 ± 0.006536 | 0.702801 ± 0.006471 | 1006.4 ± 27.7 | 1101.0 / 0.29 | 12,088.5 | n/a |
| MAGICIAN / DA3 | 0.426896 ± 0.033399 | 0.422627 ± 0.033065 | 948.8 ± 27.0 | 972.6 / 52.65 | 18,506.1 | 127/505 |
| SCONE / GT | 0.546232 ± 0.101440 | 0.540769 ± 0.100426 | 518.2 ± 160.2 | 544.5 / 0.27 | 11,980.6 | n/a |
| SCONE / DA3 | 0.178666 ± 0.152695 | 0.176879 ± 0.151168 | 426.3 ± 235.6 | 353.5 / 52.30 | 18,421.6 | 36/505 |

MAGICIAN 的 DA3–GT normalized coverage 绝对差为 `-0.283004`，相对 GT
下降 `39.87%`（保留 `60.13%`）；SCONE 的差为 `-0.367566`，相对下降
`67.29%`（保留 `32.71%`）。这是同一 mesh、同一 coverage reference、同一
starts/seeds/budget 下的场景内比较，但 n=5，只描述本实验，不作总体显著性声明。
MAGICIAN 还额外使用 RaDe-GS 先验，因此不能把两种规划器之间的差异解释成仅由
planner 本身造成。

MAGICIAN/DA3 五起点 coverage 为
`0.462491 / 0.370607 / 0.440020 / 0.452374 / 0.408990`，范围较窄。
SCONE/DA3 为 `0.000432 / 0.234616 / 0.039668 / 0.428107 / 0.190505`，
对应 pose-conditioned frame 为 `0 / 7 / 1 / 23 / 5`，path 为
`142.9 / 477.1 / 263.8 / 836.2 / 411.4 m`。这显示 SCONE/DA3 在本场景对
起点和多视图条件化状态高度敏感；这种共变支持后续诊断优先检查 pose
conditioning，但不能据此声称因果关系。四张五轨迹 preview 与 start-0
representative 均完成目视检查，没有空场景、错误 mesh 或坐标系异常。

退出后 DA3 诊断如下；GT 两组作为 renderer 自身对照，depth/ray 误差为 0。

| 规划器 | depth MAE / RMSE (m) | AbsRel / δ1.25 | ray MAE (m) | confidence-error Pearson | paired pixels |
| --- | ---: | ---: | ---: | ---: | ---: |
| MAGICIAN / DA3 | 33.596 / 41.271 | 0.7044 / 0.2469 | 39.290 | -0.3107 | 43,628,241 |
| SCONE / DA3 | 23.682 / 27.448 | 0.7668 / 0.0705 | 28.043 | -0.2367 | 51,787,138 |

离线 depth MAE 更低的 SCONE/DA3 并未得到更高 coverage，进一步说明不能只按
单个退出后深度误差选择在线规划参数。两组 DA3 的显式 fallback 均为 0；大量
unconditioned frame（MAGICIAN 378/505、SCONE 469/505）是 provider 在历史视图
不足以形成有效条件时的正常记录，不是隐式 GT 回退。

## 敏感性诊断

入口覆盖 confidence p25/p50/p75/p90、metric scale 0.9/1.1、window 1/5、process
resolution 336/672、mapping 1×/2×；固定 MAGICIAN/DA3、start 0、seed、beam、
collision 与点预算。12/12 个变体均为 6 次观测、exit 0、显式 fallback 0，
renderer GT 只进入退出后的诊断。

| 变体 | normalized coverage | pose-conditioned frames | depth MAE (m) |
| --- | ---: | ---: | ---: |
| confidence p25 | 0.093159 | 3/6 | 18.312 |
| confidence p50 | 0.068842 | 3/6 | 13.525 |
| confidence p75 | 0.010243 | 2/6 | 9.718 |
| confidence p90 | 0.009214 | 2/6 | 12.621 |
| scale 0.9 | 0.095763 | 3/6 | 21.081 |
| scale 1.1 | 0.096268 | 3/6 | 16.844 |
| window 1 | 0.000206 | 0/6 | 34.557 |
| window 5 | **0.113626** | 4/6 | 12.523 |
| resolution 336 | 0.057405 | 3/6 | 21.388 |
| resolution 672 | 0.099830 | 3/6 | 15.503 |
| mapping 1× | 0.085283 | 3/6 | 18.754 |
| mapping 2× | 0.095269 | 3/6 | 18.753 |

在本场景、单起点、短预算内，window 5 是最好的已测变体；window 1 同时出现
0/6 pose-conditioned 和近零 coverage，支持“非退化多视图条件化是关键变量”的
诊断。resolution 672 高于 336，mapping 2× 高于 1×；scale 0.9/1.1 与 1.0
邻域结果接近，因此没有证据推翻 `scene_units_per_meter=1.0` 的几何标定。confidence
阈值越高 coverage 越低，但 depth MAE 与 coverage 不单调，不能只按离线 depth
MAE 选择在线规划参数。以上排序不外推到其他起点或 101-observation 主实验。

## 可复现命令

```bash
python scripts/validate_12nw_scene_contract.py \
  --scene 12-NW-6C-7 --start-index 0 \
  --output results/12-nw-6c-7_phase4/scene_gate.json

python scripts/run_12nw_fair_experiments.py \
  --scene 12-NW-6C-7 --namespace myl21 --suite main \
  --gpu 0 --collision --output-dir results/12-nw-6c-7_phase4/main

  --scene 12-NW-6C-7 --namespace myl21 --suite sensitivities \
  --gpu 0 --collision --output-dir results/12-nw-6c-7_phase4/sensitivities

python scripts/summarize_12nw_results.py \
  --scene 12-NW-6C-7 \
  --results-root results/12-nw-6c-7_phase4/main \
  --output results/12-nw-6c-7_phase4/main/summary.json
```

DA3 执行时通过 `MAGICIAN_DA3_APPEND_PATHS` 只追加固定 source/dependency，设置
`HF_HUB_OFFLINE=1` 并使用固定 `HF_HOME`，不从网络漂移 checkpoint。

## 运行环境与测试

服务器环境为 Linux 5.15、Python 3.9.23、PyTorch 2.7.1+cu118、CUDA 11.8、
PyTorch3D 0.7.9、driver 535.230.02、RTX 3090 24 GiB。DA3 model revision
`8615eefb62f2db4f8d6ebaa59160086981672829`，source revision
`3d835ec1a5802d64a8b8b15f817a1ab54809bfe4`。远端完整测试为 49/49 通过。

## 失败与限制披露

- 首次把 `12-NW-6C-5` 的 world-coordinate transform 再应用到已预处理 OBJ，
  得到空 mask；该尝试证明了 double-transform 错误，不计入接受结果。
- 旧基线的 multi-texture loader 含未完成的 `torch.tensor()` 占位调用，smoke 在
  provider 前失败；共享实现 commit `b85c62a` 修复后才运行接受 smoke。
- 单轴三视图 smoke 退化为无 pose conditioning，产生较大误差；正式 smoke 改用
  非共线位姿且 fallback 为 0，该失败不计入结论。
- 敏感性套件曾在共享 GPU 0 上两次因外部负载争抢 OOM；失败日志与 partial cache
  已隔离保存，不作为指标，也不复用为成功轨迹。接受敏感性结果使用干净重跑。
- 所有结论只适用于本 mesh revision、配置、固定 seeds 与五个起点。
